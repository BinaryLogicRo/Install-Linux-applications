# Open with in folders

In KDE, you can configure which applications are used to open folders with.

**To add a new application or to remove an existing one:**
1. Open "System Settings".
2. Go to "Apps & Windows" -> "Default Applications".
3. Select "File Associations".
4. In the search bar, type "inode/directory".
5. Select "inode/directory" from the list.
6. Here you can add a new application or remove an existing one for opening folders.
