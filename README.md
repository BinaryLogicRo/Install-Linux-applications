# Install Linux applications

Step-by-step guides for installing and configuring applications on Debian with the KDE Plasma desktop.

## Structure

Guides are grouped by distribution release, then by topic:

- `Software/`: installing applications, with the version each guide was tested against
- `Configuration/`: system and desktop tweaks
- `Software/Assets/`: icons and other files the guides use
